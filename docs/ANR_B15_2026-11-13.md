This local personal update replaces the ANR runtime in a separate portable
application with the original files from the user-requested upstream full ZIP:
<https://github.com/apex-compute/ANR/releases/download/FG-V.B15/anr-fg-V.B15-full.zip>.
The Veyra executable remains the verified 2.1.5-anr-beta2 build, including its
corrected pixel-space motion inputs. No application rebuild is needed for this
runtime-only update. The displayed application version remains beta2; the
package manifest and upstream runtime metadata identify FG-V.B15.

metadata are used. The full package's OptiScaler, `dxgi.dll` and installers are
not installed. Veyra continues to load ANR directly from `runtime/anr`, keeping
the NVIDIA DLSS-G provider separate. All ANR configuration, model/program packs,

Upstream describes a native D3D12 resource-lifetime fix for repeated frame
generation recreation. This update does not claim independent validation of
long-duration VRAM growth or universal hardware compatibility.

`scripts/acceptance/update-apex-anr-b15.py` stages only verified donor files,
verifies the B15 provider against upstream metadata, runs the existing actual
GPU temporal-position suite and UI/restart/export acceptance, and seals a
portable ZIP with per-file hashes and CRC verification. Each test has a timeout
of at most 180 seconds, and uses E: TEMP, this task's logs and private profiles.
Results are recorded in `FINAL.json` only after successful verification.
